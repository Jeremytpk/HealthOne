Générer les fichiers initiaux

Pour créer les fichiers de démonstration dans data/, exécutez cette commande une fois dans le terminal (requiert Node.js) : 

node data/init.js

Ou utilisez les boutons Exporter ci-dessus pour générer les fichiers depuis les données actuelles de l'application.
